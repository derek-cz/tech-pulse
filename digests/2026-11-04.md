## 4. 提示词工程与 Agent 实战技巧

- **[ModelContextProtocol / Server Best Practices](https://modelcontextprotocol.io)**
  - 描述: 标准化 Context 注入范式：将本地数据、企业知识库转化为 Claude/Cursor 可调用的原子 Tool 与 Resource，告别复制粘贴。
  - 💡 实操心法: 【实操心法】将大模型从'外部旁观者'变成'内部操作者'：优先把业务数据库字典和规则表封装为只读 MCP Resource，比直接把几万字文档塞进系统提示词省 80% Token。

- **[Agent-Guardrail / Structured Schema Enforcer](https://github.com)**
  - 描述: 提示词严格边界控制：利用 Pydantic/Zod Schema 进行 LLM 结构化输出硬校验，阻断不合规字段回流。
  - 💡 实操心法: 【实操心法】防御性 Prompt 设计：在提示词尾部强制加入'如果字段不存在或无法推导，明确返回 null，禁止推测合成'，可将业务字段幻觉率降低 90% 以上。
